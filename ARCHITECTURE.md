## Карта по задачам (где что искать)

**Маршруты (частые цепочки):**

- **Каст:** `SpellPopover` → `spell:cast` → `validateSpellCast` → `resolveSpellCastWithReactions` (окно Counterspell) → `resolveSpellCast` → `executeAutomation` (снятие старой концентрации → зона → эффекты/якорь → attack/save/auto) → `applyDamage`/`applyEffectTo` → `pushRollMessage`/`pushSaveMessage` → `broadcastMaps`/`emitToken`/`emitResources` → клиент `onMapsUpdate`/`onTokenUpdate`.
- **Движение:** `TokenView.onDragEnd` → `finalizeTokenMove` → `token:move` (+ `combat:setMovement`) → `handleMovementZones`, OA-триггеры → `maps:update`.
- **Конец хода:** `combat:endTurn` → `tickActiveTurn('end')` (состояния/эффекты) → `endTurn` → `tickActiveTurn('start')` (зоны: аура, enter/exit, start), спасброски и «до конца хода» — в `room/effects.ts`.

## Архитектура

Монорепозиторий на npm workspaces: `shared`, `server`, `client`, плюс `scripts` (тесты и утилиты). Поток данных: клиент шлёт socket-событие → сервер валидирует права и данные → рассылает видимую другим игрокам версию → клиент применяет в стор (оптимистично локально, затем подтверждение сервера).

### shared (контракт и правила)

- `src/domain/*` — домен: `core` (Role/AbilityKey/`DEFAULT_ABILITIES`/`abilityMod`/`statNumber`/`statsPaired`/`clampCells`, лимиты `MAX_*`/`DEFAULT_*`), `token` (`TokenFields`/`Token`/`LibraryItem`/`TokenStatblock`/`AttackEntry`), `sheet` (`CharacterSheet`/`PlayerResources`/`ClassLevel`), `combat` (`TurnState`/`CombatState`), `effects` (`Condition*`/`Modifier*`/`Effect*`), `actions` (`ActionDef`/`Reaction*`/`AreaSpec`), `scene` (Grid/Fog/`MapInfo` c `zones: ZoneInstance[]`/`Scene`/`snapToGrid`), `chat` (`RollMessage`/`RollKind`/`labelParams` — структурные метки бросков для i18n), `room` (`Player`/`RoomState`); `src/socket/contract.ts` — socket-события `ClientToServerEvents`/`ServerToClientEvents`; `src/labels.ts` — RU-каталоги (`DAMAGE_TYPES`/`damageTypeName`, `DEFENSE_TYPE_NAMES`, `ABILITIES`, `SKILLS`); `src/normalize/*` — нормализаторы; `src/fields.ts` — реестр полей предметов/токенов (`normalizeTokenFields`/`normalizeTokenFieldsPatch`); `applyDamageDefenses`/`DamageDefense` — `domain/damage.ts`.
- `src/rollLabels.ts` — текст метки броска из `rollKind`+`labelParams` (`rollLabelText`/`rollMessageLabel`), fallback на legacy `label`.
- `src/dice.ts` — парсер выражений и бросок (чистый, покрыт тестами).
- `src/rules/` — `classes.ts` (данные классов, слоты, HP, caster level), `combat.ts` (дистанции, `attackRange`, `resolveAttack`, `countAttackAdvantage`, `weaponRolls`), `movement.ts` (стоимость шагов/достижимые клетки, `pathLeavesReach` — выход из досягаемости для OA), `resources.ts` (ресурсы, `syncResources`, `sanitizeResources`, `applyRest`), `actions.ts` (`BASE_ACTIONS`, экономика слотов), `classActions.ts` (`classFeatures` — классовые черты из ресурсов `CLASSES`), `reactions.ts` (триггеры реакционных заклинаний, `COUNTERSPELL`, реакционные черты `reactionFeatures`), `spells.ts` (типы `Spell`, нормализатор заклинаний 5e.tools, флаги `healing`/`saveHalf`), `spellLimits.ts` (лимиты кантрипов/подготовки/круга/DC из `data/spellcasting.json`; третьи кастеры EK/AT), `spellCast.ts` (`spellActionCost`, скейл кантрипов/апкаст `spellDamageExpression`, дистанция, `maxCastableLevel`, `casterStats`, `spellHasArea`/`spellAreaOrigin`), `areas.ts` (геометрия областей Ф7: `areaCells`/`tokensInArea`/`tokenFullyInArea`/`tokenCells`), `conditions.ts` (состояния Ф8: каталог, авто-эффекты — adv/dis, авто-крит, авто-провал спасбросков, запрет движения/действий, истощение), `effects.ts` (движок эффектов Ф8: модификаторы к атаке/урону/AC/спасброскам/скорости, `rollMode` — любое преимущество и любая помеха взаимно отменяются, сопротивления, `filter.targetId` для метки, `concentrationDc`, формулы вида `13+dex`, `restrictionsFor` — ограничения экономики от условий/эффектов), `automation.ts` + `automationActions.ts` (схема автоматизации R8.1: `automationForSpell` — каталог `AUTOMATION_SPELLS` (эффекты: Shield/Bless/Haste/Hex/Hold Person/Aid/…; контроль: Color Spray/Sleep/Hold Monster/Hypnotic Pattern; зоны: Web/Grease/Stinking Cloud/Hunger of Hadar; Spirit Guardians — деривация + `AUTOMATION_ADDITIONS`; Slow) + `AUTOMATION_ADDITIONS` (Shocking Grasp — запрет OA) → деривация «атака/спасбросок/автоурон» из данных → `manual`; `automationForAction` — каталог `AUTOMATION_ACTIONS` (базовые действия и черты: dash/disengage/hide/search/dodge/Всплеск действия/Второе дыхание, скейл `classLevelBonus`); ограничения экономики — `Restrictions`/`restrictionsFor` (Slow/Stinking Cloud); выпутывание — `AutomationEffect.escape`/`EffectInstance.escape` (Web); типы `AutomationDef`/`AutomationEffect`/`ZoneDef`/`ZoneInstance`/`SummonDef` — в `domain/automation.ts`; `escalate`/`wakeOnDamage`/`misdirect` (Mirror Image) — движки, призывы зарезервированы, строк без обработчика нет), `subclassSpells.ts` (выдаваемые заклинания доменов/клятв/патронов). Баррель `src/rules.ts`.
- `src/data/spells.json` (420 заклинаний, генерируется `npm run spells`; поля `healing`/`saveHalf`/`areaSpec`), `src/data/spellcasting.json` (лимиты классов), `src/data/subclassSpells.json` (выдача классам/подклассам), `src/data/features.json` (829 черт классов/подклассов, генерируется `npm run features`; ключи совпадают с ресурсами `CLASSES`); `src/spellsData.ts` — ленивый экспорт данных (`shared/spellsData`).
- `npm test` — vitest: `shared` (292: dice/rollLabels/domain/normalize/rules/…), `server` (124: `roomNormalize`, `store`, `rooms`, `handlers`, `zones`, `decode`), `client` (48: `domain/scene`, слайсы, `actionRules`, `spellIcons`); deploy-бакет (`*.deploy.test.ts`, 7+2) гоняется только `npm run test:deploy`/`verify`.

### server

- `src/index.ts` — Express + Socket.IO, статика `client/dist`, `/api/upload` (проверка magic bytes, лимит файла 50 МБ, подпапка комнаты `uploads/<code>/`, квота комнаты), health, error-middleware, graceful shutdown (flush комнат).
- `src/config.ts` — конфиг из env: `ROOM_QUOTA_MB` (`VTT_ROOM_QUOTA_MB`, дефолт 500).
- `src/store.ts` — персистентность комнат: `data/rooms/<code>.json`, атомарная запись (tmp+rename), debounce 1с, `flushRoomSaves`; uploads: `roomUploadDir`/`removeRoomUploadDir`/`dirSize`/`flatUploadSize`.
- `src/rooms.ts` — `RoomManager`: in-memory комнаты, сцена/библиотека/ресурсы/бой, контроллеры, `saveSoon`; `tokenById`/`locateToken`, `controllerOfToken`, `rollSave` (спасбросок с adv/dis и авто-провалом); чистые `controllerIdOfToken`/`controllerIdOfItem`/`hasResourceFor` экспортируются для резолверов.
- `src/roomNormalize.ts` — `hydrateRoom`: приводит прочитанный `PersistedRoom` к `Room` (legacy-конвертации, дефолты, нормализация листов/контроллеров); покрыт vitest.
- `src/socket.ts` — тонкая обёртка `io.on('connection')`, вызывает регистраторы.
- `src/socket/context.ts` — `ConnCtx`: `roomCode`/`playerId` соединения, безопасные `on`/`onDisconnect` (try/catch на каждое событие), `visibleToken`, `visibleLibrary`, `broadcast`/`broadcastAll`/`broadcastMaps`/`broadcastLibrary`, `emitToken`, `emitResources` (resources:update конкретному игроку), `notifyPlayers` (`players:update`), `applyHp` (HP через `adjustTokenHp` + рассылка токенов/ресурсов + проверка концентрации при уроне), `dmRoom`, `isDm`, `canControlToken`. `isDm` учитывает `Room.testMode` (режим тестов: права ведущего у всех игроков комнаты).
- `src/socket/guards.ts` — общая преамбула хендлеров: `playerScope` (игрок+комната), `scopedToken` (типы id, поиск токена, права контролёра/DM, `dmOnly`), `rejectIfReaction`/`rejectIfIncapacitated` (проверки с сообщением в чат).
- `src/socket/messages.ts` — `pushRollMessage`/`pushTextMessage`: единая сборка и рассылка сообщений чата (`rollKind`+`labelParams`, legacy `label`).
- `src/spells.ts` — каталог заклинаний на сервере (`findSpell`, импорт `shared/spellsData`); `socket/spells.ts` (`spell:cast`: права, выбор из листа, ячейка/слот, сбор целей по области (`origin`/`direction` + `tokensInArea`), `validateSpellCast`, шанс провала соматики от `restrictions`; `spell:endConcentration`) + `socket/spellResolve.ts` (`validateSpellCast`/`resolveSpellCast` на `AutomationDef`) + `socket/automation.ts` (generic-executor `executeAutomation`: utility/effect/attack/save/auto/manual, `applyDefEffects`; им ходят и заклинания, и действия) + `socket/effects.ts` (тик эффектов, проверка концентрации при уроне) + `socket/zones.ts` (движок зон: `createZoneFromDef`, `tickZones`, `handleMovementZones`, `removeZonesOfSource`; аура/enter-exit/start-endOfTurn, снятие по концентрации) + `socket/effectsApply.ts` (`applyEffectTo`/`removeZoneEffects`) + `socket/misdirect.ts` (Mirror Image: подмена попадания образами).
- Регистраторы по доменам: `admin`, `room` (`room:create`/`room:join`/`player:remove`/`room:settings` — режим тестов, меняет только реальный DM), `map`, `library`, `combat`, `token`, `chat`, `sheet`, `resources`, `dice`, `actions`, `spells`.
- Правило: новое socket-событие = тип в shared + регистратор + `ctx.on` + проверка прав (`isDm`/`canControlToken`) + рассылка через `visibleToken`/`visibleLibrary`.
- Туман на сервере **не фильтруется** — это клиентский UX (принятый риск, см. ниже). Статы скрываются по `showStats` и контролю владения.

### client

- `net/socket.ts` — создание socket.io; `net/bridge.ts` — транспорт: подписка на события → экшены стора, heartbeat, реконнект, автовход по `?room=`, URL-гигиена.

- `store/` — zustand: `types.ts` (GameState и `Slice`), `helpers.ts` (`throttled`, `emitInMap`/`emit`/`emitThrottled*` — socket-эмиты с mapId и троттлингом), `selectors.ts`/`hooks.ts` (`activeMapOf`/`tokenById`/`characterTokenOf`, `useActiveMap`/`useMapToken`), `uiReset.ts` (`UI_RESET`, `clearTokenUiFor`), `slices/*` (`room`, `maps`, `library`, `combat`, `actions`, `tokens`, `chat`, `sheet`, `view`, `reactions`), `useGameStore.ts` — композиция.
- `components/` — Konva-стол (`TableTop`, `TokenView`, `GridLayer`, `ZoneLayer` — заливка зон/областей), панели (карты, токены, чат, инициатива, ресурсы, игроки, `ActionPanel`), модалки (`GridSettingsModal`, `RoomSettingsModal` — режим тестов), `CritOverlay`/`ThreeD20` (ленивый three.js), `SpellIcon`/`spellIcons` (420 рукописных иконок; красный кружок у неавтоматизированных заклинаний, `spellAutomated`), `SpellsPanel` (выбор заклинаний), `SpellPopover` (накладывание: круг/апкаст, Adv/Dis, пометка «эффект не автоматизирован»; после попапа — выбор цели/области на карте), `AimPanel` (режимы выбора цели: `targeting` — клик по токену для любой способности/атаки, `aim` — прицеливание области, `multiTarget` — выбор цели на каждый луч; курсор-прицел и подсветка в `TableTop`), `DamageDefensesForm` (сопротивления/иммунитеты/уязвимости юнита), `ConditionIcon`/`ConditionChips`/`ConditionsOverlay`/`ConditionsForm` (состояния: глифы, чипы над токенами/в инициативе, управление в меню токена), `EffectChips` (активные эффекты Ф8; чипы над токенами и в панелях, снятие в меню токена, концентрация в `ResourcesPanel`). Права в UI — `useIsDm`/`isDmWith` (`lib/control.ts`): реальный DM или режим тестов.
- `screens/` — `JoinScreen`, `AdminScreen`, `TableScreen`. `lib/` — `api.ts` (загрузка), `control.ts` (клиентские проверки контроля — только UX), `sheet.ts`, `spells.ts` (ленивый `loadSpells()`), `useImage.ts`, `branding.ts` (иконка/заголовок local/prod), `id.ts` (`newId` с fallback для небезопасного контекста).
- `styles/` — CSS по фичам, подключается через `styles.css` (`@import` в исходном порядке).
- `window.__vtt` — стор в window для e2e.

### scripts

- `build-spells.ts` (`npm run spells`, tsx) — сборка данных заклинаний (5e.tools → `shared/src/data/spells.json`) и лимитов кастеров (`shared/src/data/spellcasting.json`) (см. `shared/src/rules/spells.ts`, `spellLimits.ts`).
- `e2e.mjs` + `e2e/*` — сценарии в браузере (Puppeteer), общий `state.mjs` (`S`) и последовательные `await import()`; скриншоты в `artifacts/e2e`, маркер прогона `artifacts/e2e/.run`.
- `smoke.mjs` + `smoke/*` — серверные socket-сценарии, общий `S`; включает `04b-spells` (каст: ячейка, спасбросок, урон), `08-conditions` (состояния), `09-effects` (Shield/Bless/Aid/Hex + концентрация и долгий отдых), `10-test-mode` (права ведущего у игроков), `06-robustness` (битые payload). Дебаг-прогон подмножества: `SMOKE_ONLY=09,10 node scripts/smoke.mjs` (00-setup + выбранные сценарии; зависимости от предыдущих не подтягиваются).
- `smoke.mjs`/`e2e.mjs` — снимок комнат до прогона и удаление созданных в `finally`/по watchdog (чистка после падения).
- `lib/` — `check.mjs` (тихий вывод, `VTT_VERBOSE=1`), `e2e-helpers.mjs` (`findButton`, `waitFor`/`nextFrame` — ждать состояние/кадр вместо `sleep`), `smoke-helpers.mjs` (`eventOnce`, `addLibrary`, `setCharacter`, `spawnToken`, `setSheet`, `waitToken`), `png.mjs`, `rooms-cleanup.mjs` (`snapshotRoomCodes`/`deleteNewRooms`).
- Тесты: серверные фикстуры — `server/src/test/fixtures.ts` (`makeToken`/`makeRoom`/`makeCombatRoom`/`makeResources`), тест-кит контекста — `server/src/test/ctx.ts` (`makeConnCtx` поверх реального `createCtx` и in-memory транспорта; `invoke`/`emitted`/`advance`); клиентские — `client/src/test/fixtures.ts`.
