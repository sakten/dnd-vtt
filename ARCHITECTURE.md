**Маршруты (частые цепочки):**

- **Каст:** `SpellPopover` → `spell:cast` → `validateSpellCast` → `resolveSpellCastWithReactions` (окно Counterspell) → `resolveSpellCast` → `executeAutomation` (снятие старой концентрации → зона → эффекты/якорь → attack/save/auto) → `applyDamage`/`applyEffectTo` → `pushRollMessage`/`pushSaveMessage` → `broadcastMaps`/`emitToken`/`emitResources` → клиент `onMapsUpdate`/`onTokenUpdate`.
- **Движение:** `TokenView.onDragEnd` → `finalizeTokenMove` → `token:move` (+ `combat:setMovement`) → `handleMovementZones`, OA-триггеры → `maps:update`.
- **Конец хода:** `combat:endTurn` → `tickActiveTurn('end')` (состояния/эффекты) → `endTurn` → `tickActiveTurn('start')` (зоны: аура, enter/exit, start), спасброски и «до конца хода» — в `room/effects.ts`.

## Архитектура

Монорепозиторий на npm workspaces: `shared`, `server`, `client`, плюс `scripts` (тесты и утилиты). Поток данных: клиент шлёт socket-событие → сервер валидирует права и данные → рассылает видимую другим игрокам версию → клиент применяет в стор (оптимистично локально, затем подтверждение сервера).

### server

- `src/index.ts` — Express + Socket.IO, статика `client/dist`, `/api/upload` (проверка magic bytes, лимит файла 50 МБ, подпапка комнаты `uploads/<code>/`, квота комнаты), health, error-middleware, graceful shutdown (flush комнат).
- `src/config.ts` — конфиг из env: `ROOM_QUOTA_MB` (`VTT_ROOM_QUOTA_MB`, дефолт 500), `SAVE_DEBOUNCE_MS` (`VTT_SAVE_DEBOUNCE_MS`, дефолт 120000), `CHAT_SAVE_DEBOUNCE_MS` (`VTT_CHAT_SAVE_DEBOUNCE_MS`, дефолт 120000).
- `src/store.ts` — персистентность комнат: `data/rooms/<code>.json` (чат — отдельный `<code>.chat.json`, пишется только при изменении), атомарная запись (tmp+rename), debounce из env, `flushSaves`; uploads: `roomUploadDir`/`removeRoomUploadDir`/`dirSize`/`flatUploadSize`.
- `src/rooms.ts` — `RoomManager`: in-memory комнаты, сцена/библиотека/ресурсы/бой, контроллеры, `saveSoon`; `tokenById`/`locateToken`, `controllerOfToken`, `rollSave` (спасбросок с adv/dis и авто-провалом); чистые `controllerIdOfToken`/`controllerIdOfItem`/`hasResourceFor` экспортируются для резолверов.
- `src/roomNormalize.ts` — `hydrateRoom`: приводит прочитанный `PersistedRoom` к `Room` (legacy-конвертации, дефолты, нормализация листов/контроллеров); покрыт vitest.
- `src/socket.ts` — тонкая обёртка `io.on('connection')`, вызывает регистраторы.
- `src/socket/context.ts` — `ConnCtx`: `roomCode`/`playerId` соединения, безопасные `on`/`onDisconnect` (try/catch на каждое событие), `visibleToken`, `visibleLibrary`, `broadcast`/`broadcastAll`/`broadcastMaps`/`broadcastLibrary`, `emitToken`, `emitResources` (resources:update конкретному игроку), `notifyPlayers` (`players:update`), `applyHp` (HP через `adjustTokenHp` + рассылка токенов/ресурсов + проверка концентрации при уроне), `dmRoom`, `isDm`, `canControlToken`. `isDm` учитывает `Room.testMode` (режим тестов: права ведущего у всех игроков комнаты).
- `src/socket/guards.ts` — общая преамбула хендлеров: `playerScope` (игрок+комната), `scopedToken` (типы id, поиск токена, права контролёра/DM, `dmOnly`), `rejectIfReaction`/`rejectIfIncapacitated` (проверки с сообщением в чат).
- `src/socket/messages.ts` — `pushRollMessage`/`pushTextMessage`: единая сборка и рассылка сообщений чата (структурные `rollKind`+`labelParams`; явный `label` — только повтор из чата).
- `src/spells.ts` — каталог заклинаний на сервере (`findSpell`, импорт `shared/spellsData`); `socket/spells.ts` (`spell:cast`: права, выбор из листа, ячейка/слот, сбор целей по области (`origin`/`direction` + `tokensInArea`), `validateSpellCast`, шанс провала соматики от `restrictions`; `spell:endConcentration`) + `socket/spellResolve.ts` (`validateSpellCast`/`resolveSpellCast` на `AutomationDef`) + `socket/automation.ts` (generic-executor `executeAutomation`: utility/effect/attack/save/auto/manual, `applyDefEffects`; им ходят и заклинания, и действия) + `socket/effects.ts` (тик эффектов, проверка концентрации при уроне) + `socket/zones.ts` (движок зон: `createZoneFromDef`, `tickZones`, `handleMovementZones`, `removeZonesOfSource`; аура/enter-exit/start-endOfTurn, снятие по концентрации) + `socket/effectsApply.ts` (`applyEffectTo`/`removeZoneEffects`) + `socket/misdirect.ts` (Mirror Image: подмена попадания образами).
- Регистраторы по доменам: `admin`, `room` (`room:create`/`room:join`/`player:remove`/`room:settings` — режим тестов, меняет только реальный DM), `map`, `library`, `combat`, `token`, `chat`, `sheet`, `resources`, `dice`, `manualRolls`, `actions`, `spells`.
- Правило: новое socket-событие = тип в shared + регистратор + `ctx.on` + проверка прав (`isDm`/`canControlToken`) + рассылка через `visibleToken`/`visibleLibrary`.
- Туман на сервере **не фильтруется** — это клиентский UX (принятый риск, см. ниже). Статы скрываются по `showStats` и контролю владения.
