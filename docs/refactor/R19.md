# R19. Метамагия (Careful Spell и др.): архитектура каст-модификаторов. P3, S/M (проектирование; решить перед реализацией).

Назад: [REFACTOR.md](../../REFACTOR.md).

Контекст: метамагия сорка меняет конкретный каст, не спеку: Careful (защищённые цели — автоуспех сейва + 0 вместо половины), Heightened (помеха на сейв цели), Twinned (вторая цель), Quickened (действие → бонусное),
Subtle (компоненты/тишина), Empowered (переброс костей), Extended (длительность). «Природно безопасные» спеллы (Spirit Guardians) — другое правило: `side:'hostile'` исключает союзников из целей, а не форсирует им успех.
Варианты архитектуры:
- **A. Оверрайд эффективного дефа на касте:** `def = { ...baseDef, careful: true }`; `runSave` читает поле дефа, отсутствие = false (Fireball ничего не декларирует). Плюсы: дешевле некуда, один резолв на врождённое
свойство и метамагию, аддитивно. Минусы: 8 опций → поля-свалка в `AutomationDef` и ветки в 5 подсистемах (сейвы/таргетинг/экономика/броски/длительность), валидация размазана.
- **B. Namespaced каст-параметр:** `spell:cast.metamagic = { careful?: … }`; подсистемы читают свои ключи (`runSave` — careful, `attackSources` — heightened, экономика — quickened). Плюсы: чистый контракт каста,
стоимость/валидация в одном месте. Минусы: врождённое свойство спела и каст-параметр — два источника одного правила.
- **C. Пайплайн трансформов:** опция = данные + `apply(def, ctx)`/`validate`/`cost`; хендлер прогоняет `def = transforms.reduce(...)` (Careful → `{...def, careful:true}`, Heightened → `saveDisadvantageIds`, Twinned →
`targets+1`, Quickened → `castCost:'bonus'`). Плюсы: композиция, порядок зафиксирован, unit-тесты на опцию, путь к CUSTOM-метамагии. Минусы: дороже сейчас; для Quickened/Twinned всё равно нужны потребители в
экономике/таргетинге.
Рекомендация: для первой опции (Careful) — A; переход на C при ≥2 опциях или первой «не-деф» (Quickened/Twinned) — по тому же принципу ожидания, что R14 («ждём 2+ реактивных спелла»). B — промежуточный, если хочется
заранее вычистить контракт каста.
Зафиксировано по обсуждению: **без UI выбора** — авто-союзники среди целей каста (`sideMatches(caster, t, 'ally')`); кап по CHA — решить при реализации (значение поля vs константа). Стоимость и лимиты (Sorcery Points,
«спелл требует сейв») — в хендлере каста, не в спеках.
Решение (сессия 25, после R16 4.3): статические модификаторы (инвокации) — патчи по именованным путям поверх записи (`InvocationMechanics.patches`:
`automation.damage.abilityMod`/`automation.force`/`meta.range.distance.amount`, применяет `applyPatch`); метамагия — тот же пайплайн трансформов: def-часть патчами, каст-контекст (Quickened/Twinned: экономика/цели) — в
хендлере каста.
